# 数据说明

本目录不包含原始行情数据。研究使用的全市场 1 分钟数据约 819 GB，且可能受供应商授权与再分发条款约束，因此开源仓库只提供数据规格、读取代码和结果文件。只要准备出符合下述字段与主键约定的数据，即可运行 `src` 中的完整流水线。

## 1. 实际使用的数据

| 数据层 | 时间范围 | 粒度与组织 | 主要用途 |
|---|---|---|---|
| 全市场 1 分钟 K 线 | 2004-01-02 至 2026-07-31；研究计算从 2016-05 开始 | 每个交易日一个 HDF5 文件，文件名 `YYYYMMDD.hdf` | 计算日度原子因子 |
| 全 A 日频宽表 | 2002-01-04 至 2026-07-31 | 每个字段一个 HDF5；行是交易日，列是股票 | 交易日历、收益标签、换手、市值、行业、交易状态与指数池 |
| 指数成分与指数行情 | 与日频数据一致 | HDF5 历史面板 | 构造四个历史股票池与基准收益 |
| 财务和估值风格 | 2016-07 至 2026-06 月末 | point-in-time 横截面 | 构造 BP、DP、成长和盈利风格，完成 S3 检验 |

研究不使用逐笔成交；集合竞价与五档盘口字段也不进入当前 18 个正式因子。

## 2. 股票代码、日期与主键

内部标准代码使用后缀式：`000001.SZ`、`600519.SH`。调用 `cjpy` 时转换为前缀式：`SZ000001`、`SH600519`。

- 分钟文件名：`YYYYMMDD.hdf`；
- 日频日期：建议读为 `DatetimeIndex`；
- 日度原子唯一键：`trade_date + code`；
- 月末回测唯一键：`form_month + code`；
- 研究股票范围：沪深 A 股，剔除 `.BJ`、`.HK` 及其他非研究代码。

代码转换示例：

```python
def suffix_to_prefix(code: str) -> str:
    number, exchange = code.split(".")
    return exchange + number

assert suffix_to_prefix("000001.SZ") == "SZ000001"
```

## 3. 1 分钟行情

### 3.1 文件与数据形状

每个交易日一个文件：

```text
minute_1m/
├── 20160503.hdf
├── 20160504.hdf
└── ...
```

每只股票每个正常交易日应有 240 行：09:31-11:30 与 13:01-15:00，不含 09:25 集合竞价。文件内部为长表，股票为主序；同一股票的 240 行连续，但股票存放顺序不应被假定，必须使用 HDF5 label 数组定位。

实际 HDF5 结构为 pandas 固定格式的底层块：

- `block0_values`：数值矩阵；
- `axis0`：28 个字段名；
- `axis1_label0`：分钟位置标签；
- `axis1_label1`：股票标签；
- 对应的 level 数组：真实时间与股票代码。

`src/lib_fdrive.py` 已封装读取与散布逻辑，返回 `MinuteDay`，再通过 `scatter` 生成形状为 `(股票数, 240)` 的字段矩阵。

### 3.2 使用字段

当前因子只依赖以下 8 个核心字段：

| 字段 | 类型 | 含义 | 使用位置 |
|---|---|---|---|
| `open` | float64 | 后复权分钟开盘价 | 数据完整性与扩展分析 |
| `high` | float64 | 后复权分钟最高价 | 分钟振幅、B2/B2a |
| `low` | float64 | 后复权分钟最低价 | 分钟振幅、B2/B2a |
| `close` | float64 | 后复权分钟收盘价 | 分钟收益、路径、趋势与极值点 |
| `vol` | float64 | 分钟成交量 | 量占比、领先滞后、集中度与量价确认 |
| `amount` | float64 | 分钟成交额，单位为元 | B2a 与口径勾稽 |
| `factor` | float64 | 当日复权因子 | 口径验证，不直接进入因子 |
| `num` | float64 | 成交笔数 | 当前正式因子未使用 |

原始文件还含五档买卖价和五档买卖量，但当前版本不使用这些字段。

### 3.3 推荐的逻辑表样式

不要求物理文件一定是 HDF5。若替换数据源，只需在访问层适配为以下逻辑长表：

| code | datetime | open | high | low | close | volume | amount |
|---|---|---:|---:|---:|---:|---:|---:|
| 000001.SZ | 2024-03-18 09:31:00 | 10.51 | 10.53 | 10.49 | 10.52 | 166555 | 139335339 |
| 000001.SZ | 2024-03-18 09:32:00 | 10.52 | 10.52 | 10.48 | 10.49 | 41612 | 34772315 |

### 3.4 分钟派生字段

设第 `t` 分钟收盘价为 `C_t`、成交量为 `V_t`：

```text
ret_1m[t]       = log(C_t / C_{t-1})
amplitude[t]    = (high_t - low_t) / C_{t-1}
volume_share[t] = V_t / sum(V)
volume_change[t]= V_t / V_{t-1} - 1
```

相邻价格无效、前一分钟成交量非正、分母非正或有效样本不足时输出 NaN，不做零填充。

### 3.5 读取范例

使用项目访问层：

```python
from pathlib import Path
from lib_fdrive import read_minute_day

day = read_minute_day(Path(r"E:\market_data\minute_1m\20240318.hdf"))
close = day.scatter("close")   # shape: (n_stocks, 240)
volume = day.scatter("vol")
print(day.codes[:5], close.shape)
```

若数据不是同样的 HDF5 内部结构，请改写 `read_minute_day`，保持返回对象的 `codes`、`times` 和 `scatter(field)` 接口不变，其余因子代码无需修改。

## 4. 日频宽表

### 4.1 物理形式

每个字段或主题一个 HDF5，读取后为“日期 × 股票”的宽表：

| trade_date | 000001.SZ | 600519.SH | ... |
|---|---:|---:|---:|
| 2024-03-18 | value | value | ... |
| 2024-03-19 | value | value | ... |

### 4.2 正式使用的文件

| 文件或主题 | 口径 | 用途 |
|---|---|---|
| `close.hdf` | 后复权收盘价 | 交易日历、上市边界、下月收益、动量与反转 |
| `turn.hdf` | 换手率，数值 1.04 表示 1.04% | A2d、S2 换手风格、过滤与诊断 |
| `cap.hdf` | 流通市值，单位万元 | 市值中性化 |
| `zhangting.hdf` | 1 表示涨停 | 可交易过滤 |
| `dieting.hdf` | 1 表示跌停 | 可交易过滤 |
| `tingpai.hdf` | 0 表示停牌，1 表示正常交易 | 停牌过滤 |
| `stpanduan.hdf` | 1 表示 ST 或 *ST | ST 过滤 |
| `industry_sw.hdf` | 申万一级行业日频面板 | 行业中性化 |
| `index_weight.hdf` | 历史指数成分与权重 | 沪深300、中证500、中证1000、中证全指股票池 |
| `price_index.hdf` | 指数收盘点位 | 基准收益 |

`st.hdf` 在原始数据中全为 1，属于无效字段，代码不使用它。

### 4.3 读取范例

```python
from lib_fdrive import read_base_wide, read_index_weight

close = read_base_wide("close")
turnover = read_base_wide("turn")
hs300_weight = read_index_weight("SH000300")

close.index = close.index.astype("datetime64[ns]")
```

## 5. 风格与财务数据

S1 和 S2 所需的规模、波动率、换手率、动量与反转均由本地日频数据构建。S3 额外需要以下 point-in-time 数据：

| 原始字段 | 构造风格 | 对齐规则 |
|---|---|---|
| `PBLF` | `BP = 1 / PBLF` | 形成月末 as-of |
| `股息率TTM` | DP | 形成月末 as-of |
| `ROETTM` | 盈利 | 形成月末 as-of |
| `营业收入增长率(%)`、`公布日` | 成长 | 只使用形成月末前已公布的最新报告期 |

使用 `cjpy` 的简化范例：

```python
import cjpy

codes = ["SZ000001", "SH600519"]
snapshot = cjpy.get_factor_data(
    code=codes,
    date=["20240628"],
    factors=["PBLF", "股息率TTM", "ROETTM"],
)
```

请在本机持久化 token，或通过 `CJ_API_TOKEN` 环境变量传入。不要把 token 写入源码、配置样例或提交历史。

## 6. 中间数据与最终面板

默认缓存根目录由 `HF_CACHE_ROOT` 指定，结构如下：

```text
hf_factor_cache/
├── daily/                       # 日频基础表的 Parquet 缓存
├── factors_atomic/parts/        # 分批日度原子面板
├── panels/factors_daily/        # 20 日滚动因子
├── panels/monthly_panel.parquet # 月末截面与下月收益
├── panels/processed/            # S1/S2 处理后面板
└── styles/                      # 九风格 point-in-time 面板
```

关键逻辑表：

| 表 | 一行代表什么 | 关键字段 |
|---|---|---|
| 日度原子面板 | 一只股票在一个交易日 | `trade_date`、`code`、16 个原子量及诊断列 |
| 日度因子面板 | 一只股票在一个交易日 | 18 个 20 日滚动因子 |
| 月末回测面板 | 一只股票在一个形成月末 | 股票池、行业、市值、交易过滤、下月收益、因子值 |
| 处理后面板 | 一个股票池、一种中性化方案下的月末股票 | 原始因子、去极值值、中性化值、收益标签 |

## 7. 数据质量检查

替换或准备数据时至少验证以下事项：

1. 正常交易日每股应有 240 个连续竞价分钟；
2. 停牌股可能仍有冻结价格和零成交量的 240 行，必须整日剔除；
3. 成交量可能受复权因子缩放，日内相对量不受影响，但跨日绝对量应改用换手率；
4. 分钟成交额之和应与日频成交额一致；
5. 不同日频表的股票列可能不完全相同，合并时按代码显式对齐；
6. 指数成分必须使用历史时点数据，不能用当前成分回填历史；
7. 行业与财务数据必须按形成月末 point-in-time 对齐，禁止使用未来公布值；
8. 新股、ST、停牌和涨跌停过滤必须在形成月末可获得的信息范围内完成。

项目提供的验证脚本：

- `92_verify_atoms.py`：独立慢循环与向量化原子逐值对照；
- `93_probe_vol_caliber.py`：分钟量与日成交量口径检查；
- `94_check_amount.py`：分钟成交额与日成交额勾稽；
- `95_debug_panel.py`：月末面板过滤链诊断；
- `96_check_neutral.py`：中性化后的相关性与行业均值检查。

## 8. 数据如何进入各模块

| 模块 | 价格输入 | 成交输入 | 日频辅助 |
|---|---|---|---|
| A 微观结构 | 分钟 close、high、low | volume | 日换手率 |
| B 时序特征 | 分钟收益、振幅、累计收益 | volume、amount、量变化 | 无额外字段 |
| C 成交集中度 | 分钟收益符号 | volume | 无额外字段 |
| 月度回测 | 后复权日收盘价 | 换手率 | 市值、行业、状态、指数成分、指数行情 |
| S3 风格检验 | 动量、反转 | 换手、波动 | BP、DP、成长、盈利 |

数据层的目标不是复制某一种供应商格式，而是稳定提供上述语义、时点和单位。若数据源不同，应优先修改 `src/lib_fdrive.py` 的访问层并重新运行口径验证，而不是改动因子定义。
